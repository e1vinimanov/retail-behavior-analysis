# CV project entry

**Retail Customer Behavior Analysis | SQL, Python | Independent portfolio project**

- Analyzed 9.86 million retail purchase and cart events using PostgreSQL and Python, measuring 30-day repeat purchasing and seven-day cart-to-purchase conversion with fixed follow-up windows.
- Found that 92.4% of observed seven-day cart-to-purchase conversions occurred within 24 hours, and presented monthly trends, measurement limitations and follow-up testing recommendations in an interactive HTML report.
